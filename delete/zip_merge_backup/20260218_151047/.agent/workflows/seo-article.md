# SEO記事作成ワークフロー

このワークフローは5つのPhaseで構成される。各Phaseは順番に実行し、ゲート条件を満たしてから次に進む。
各Phaseの詳細手順はSkillsとして定義されている。エージェントはPhase実行時に対応するSkillを自動で読み込む。

## 入力情報
ユーザーから以下4項目を受け取る（必須）。
- {target_keyword} = ターゲットキーワード
- {article_purpose} = 記事の目的（リード獲得/信頼性構築/サービス認知/教育コンテンツのいずれか）
- {mode} = 実行モード（`new`/`rewrite` または `新規`/`リライト`）
- {base_article_html_or_url} = 元記事URLまたはHTML（`mode=new` の場合は `なし` で可）

入力不足時（空起動を含む）は記事執筆を開始せず、必ず以下の文面で返す。

対策KW：
この記事の目的：
モード（新規 or リライト）
元記事のURL：

4項目すべてが入っていないと、記事執筆を開始できません。
（新規の場合、元記事のURLは「なし」でOK）

## Phase1：入力受付＋検索意図分析
seo-phase1-intentスキルの手順に従い、以下を出力する。
- 検索意図4要素の分析（各要素の「記事での扱い方」含む）
- 記事の本軸（解決手順 or 事実）の決定
- ゴールシナリオ2パターン

**ゲート条件**：上記3点がすべて出力されるまでPhase2に進めない。

## Phase2：競合調査＋ギャップ分析
seo-phase2-competitorスキルの手順に従い、以下を出力する。
- PAA質問の4分類
- 関連検索キーワードの優先順位
- 上位5サイトの個別分析（1サイトずつ順番に。まとめて処理しない）
- 検索意図充足度スコアリング
- 共通トピック一覧、差別化トピック一覧
- ギャップ分析
- 差別化の軸（1行）

**ゲート条件**：上記すべてが出力されるまでPhase3に進めない。

## Phase3：戦略・構成設計
seo-phase3-strategyスキルの手順に従い、以下を出力する。
- ペルソナ定義（BtoBの場合は担当者＋決裁者の2名）
- 構成案（全H2/H3/H4と使用パーツ指定＋カスタマージャーニーフェーズ指定）
- 自社USP配置計画（3つ以上のUSPと配置箇所）
- 1次情報・図表の実装計画（4分類）
- 記事全体の想定総文字数
- `mode=rewrite` の場合、`rewrite_plan.md` に以下を必須出力する：
  - `Internal Link Plan`
  - `主クラスター`
  - `候補リンク（最大6）`
  - `最終採用リンク（最大3）`
  - `配置セクション（H2）`
  - `採用理由`

**ゲート条件**：上記すべてが出力されるまでPhase4に進めない。

## Phase4：完全執筆（HTML出力）
seo-phase4-writingスキルの手順に従い、以下を出力する。
- タイトル（32文字前後）とメタディスクリプション（120文字前後）
- 記事全文（HTML形式）
- CTAが記事中盤と末尾の2箇所に配置
- FAQが5問以上
- 1,000文字ごとに1つ以上の視覚要素

**ゲート条件**：上記すべてが揃うまでPhase5に進めない。writing-rulesに違反する箇所がないこと。

## Phase5：検証・最終出力
seo-phase5-validationスキルの手順に従い、以下をチェックする。
- SEO要件チェック
- LLMO対策チェック
- Writing Rulesチェック（.agent/rules/writing-rules.mdに準拠）
- E-E-A-Tスコアカード評価（合計15点以上で合格）
- コンテンツ品質チェック

すべて合格後、最終出力する。
- 完成版HTML
- タイトルとメタディスクリプション（プレーンテキスト）
- 画像プレースホルダー一覧
- プロジェクトの進捗管理表に完了ステータスを追記・更新済み

出力後、プロジェクトの進捗管理表（優先度レポートや履歴ファイル）に完了ステータスを追記・更新する。

出力後、メタコメント（「以上です」「修正があれば」等）は一切付けない。
