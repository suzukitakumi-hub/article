# Abitus Workspace

このフォルダは **Abitus（CFE関連）** のコンテンツ専用ワークスペースです。

## フォルダ構成

```
abitus_workspace/
├── CFEとは/          # CFE資格の基本情報記事
├── CFE年収/          # CFE資格者の年収関連記事
├── CFE難易度/        # CFE試験の難易度関連記事
├── コンプライアンス違反/  # コンプライアンス違反記事
├── 不正会計/         # 不正会計関連記事
└── .agent/
    └── workflows/    # SEO記事作成・リライトワークフロー
```

## 使い方

### 1. 別ウィンドウでAntigravityを起動

1. VS Codeで新しいウィンドウを開く
2. このフォルダ（`abitus_workspace`）を開く
3. Antigravityを起動

### 2. 利用可能なワークフロー

- `/seo-article-writing` - 新規SEO記事執筆
- `/seo-article-rewrite` - 既存記事のSEOリライト
