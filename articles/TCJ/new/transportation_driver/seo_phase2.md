# Phase2：競合調査＋ギャップ分析結果

**ターゲットキーワード**: `外国人 トラックドライバー`

## 1. PAA質問の4分類
- **What系**: 特定技能「自動車運送業」とは？ 何ができる？ 在留期間は？
- **How系**: どうやって免許を切り替える（外免切替）？ 試験の難易度は？ 採用手順は？
- **Why系**: なぜ外国人ドライバーが必要か？（2024年問題） なぜ事故が心配されるか？
- **Which系**: どの国の人材が良いか？ どの支援機関・教育機関が良いか？

## 3. ギャップ分析

### 共通トピック（Must）
- 特定技能1号の要件（N4、技能試験）。
- 免許の壁（日本の免許取得、外免切替）。
- 2024年問題、人手不足の背景。

### 差別化トピック（Want）
- **「現場で使える日本語」の具体例**（配送伝票、無線、接客）。
- 事故リスクに対する**「教育による解決策」の提示**。
- 大手（ヤマト等）の事例から見る「成功のポイント」。

### 4要素ギャップ分析
- **ボトルネック**: 競合は「制度（Hard）」か「丸投げサービス（Solution）」のどちらかに偏っている。
- **機会**: 「制度の複雑さ」と「現場の不安（事故・言葉）」の両方を、**「教育」という切り口で接続する記事**がない。

## 4. 差別化の軸（コンセプト）
**「免許・制度の『入り口』から、事故ゼロ・定着の『出口』まで見通せる、"教育視点"の採用実務ガイド」**

- **FDSOとの違い**: 彼らは「海外で免許取らせて連れてくる（仕組み）」が強み。TCJは「**入社後の現場適応・安全を守るための"言葉と意識"の教育**」に強みを持たせる（あるいは補完関係）。
- **JTA/MLITとの違い**: 難解な役所言葉を排除し、「で、うちは何をすればいいの？」に即答するわかりやすさ。
