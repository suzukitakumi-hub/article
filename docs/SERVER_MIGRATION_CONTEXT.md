# 外国人材Times サーバー構築・移管に関する経緯と対応方針メモ

**作成日**: 2026-02-02
**概要**: 外国人材Times（サブドメイン運用）の立ち上げ経緯、学長指摘への対応、XServer移管方針の整理。

---

## 1. 現状の構成と立ち上げ経緯

### 現状
- **URL**: `times.tcj-education.com`（サブドメイン）
- **システム**: WordPress
- **サーバー**: 新規契約したサーバー（WCE本体とは別）

### なぜ「WCE本体（`tcj-education.com`）」のディレクトリに入れなかったのか？
当初はWCE本体配下（ディレクトリ）での構築を検討したが、以下の理由により**現場判断で「サブドメイン・別サーバー」運用**に変更した。

1.  **コストの問題**
    - WCE管理ベンダー（エレファントプラス社）に見積もりを取ったところ、構築のみで**約120万円**と高額だった。
    - また、軽微な改修でも都度費用が発生する見込みだった。
2.  **スピードと柔軟性の問題**
    - 既存ベンダー経由では、仕様変更や記事投下のたびに調整コストがかかり、メディア運用のスピード感（PDCA）が出せないと判断。
    - 別ベンダーにてWordPressを構築することで、低コストかつ即日の修正対応が可能な体制を作った。
3.  **リスク回避**
    - 既存のWCEサイト（LP含む）と同じ環境に同居させることで、サーバー負荷による表示速度低下や、プラグイン干渉によるサイト崩れのリスクを避けたかった。

---

## 2. 学長からの指摘事項（2026/01時点）

**指摘内容**:
「TCJ Recruitment LP内に構築する話だったはずだが、別サイトに見える。WCE傘下に入れる承認だったはず。ドメインパワーは引き継げているのか？導線がないではないか。」

**指摘の背景**:
- 「仕様（サーバー構成）が承認時と変わっている」ことへのプロセス指摘。
- 「TCJのブランド資産（ドメイン）が無駄になっていないか」という懸念。

---

## 3. 対応方針と回答ロジック

### A. 仕様変更の正当性（なぜ変えたか）
- **「コスト120万円の削減」と「運用スピード確保」が最大の理由。**
- 目的である「TCJのドメインパワー活用」は、**サブドメイン運用**によってGoogleからは関連サイトとして認識されるため、SEO的にも達成されている。
- つまり、「手段は変えたが、目的（成果とコストパフォーマンス）のために最適な選択をした」。

### B. 学長指摘（導線・一体感）への対応
- **導線設置**: LP（`tcj-recruitment`）からメディアへのリンク、およびメディアからLPへの送客導線を早急に設置し、ユーザー視点での「一体感」を作る。
- **インフラ統合**: 情シス提案の「XServer移管」に乗る。

---

## 4. XServer移管の方針（情シス提案への回答）

**提案**: 「TCJ-EDUCATION.COM関連サイトをXServerへ移管次第、外国人材サイトもXServerへ移管する」

**判断**: **GO（賛成）**

**条件と運用ルール**:
- **「同居はするが、部屋は分ける」**
- WCE本体と同じXServerアカウント内には入るが、**ディレクトリ（フォルダ）は完全に分ける**。
- WordPressの管理画面も別々のまま運用する。
- **理由**: WCE本体のシステム・プラグインとの干渉を防ぎ、外国人材Times側の自由なカスタマイズ権限を維持するため。

**メリット**:
- インフラがWCE本体と一元化されるため、学長の「WCE傘下に入れる」という要望に対し、物理的にも応える形になる。
- XServerのハイスペックな環境を利用でき、表示速度向上が見込める。
