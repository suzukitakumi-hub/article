# Webinar CTA Project Overview

## 目的
- Classic Editor環境で、ウェビナーCTAを毎回手作業で作る負担をなくす。
- 記事内にショートコードを挿入するだけで、統一デザインのCTAを自動生成する。

## 背景
- 現在、申込ページはサイト内に存在している（例: `/seminar/sem32`）。
- LP画像など必要アセットはアップロード済み。
- 記事ごとにHTMLを手作成すると工数が大きく、デザインの統一も崩れやすい。

## 方針（MVP）
- WordPressプラグインを作成し、ショートコードでCTAを出力する。
- 使用例: `[tcj_webinar_cta slug="sem32"]`
- `slug`指定のみで以下を自動取得してHTML生成:
  - タイトル
  - URL
  - アイキャッチ画像
  - 日時（取得できる場合）

## 実装仕様（要約）

### ショートコード
- 名称: `tcj_webinar_cta`
- 必須属性:
  - `slug`
- 任意属性:
  - `button_text`
  - `headline`
  - `variant`
  - `utm_source`
  - `utm_medium`
  - `utm_campaign`

### データ取得
- 優先探索:
  1. `/seminar/{slug}`
  2. `seminar`投稿タイプ `name={slug}`
- 取得項目:
  - post title
  - permalink
  - featured image
  - excerpt
  - 日時メタ（候補キーを順に探索）

### キャッシュ
- Transientキーでキャッシュ
- デフォルトTTL: 6時間
- 管理画面からキャッシュ削除可能

### フォールバック
- `slug`不正時:
  - 管理者には警告
  - 閲覧者には最小CTA（`/seminar/`へのリンク）
- 画像・日時が取れない場合:
  - 該当要素を非表示にして出力継続

### 管理画面（設定）
- デフォルトボタン文言
- UTMデフォルト値
- キャッシュTTL
- フォールバック文言/リンク
- 日時メタキー候補

### セキュリティ
- 出力時のエスケープ徹底（URL/テキスト/属性）
- 設定保存時に権限チェックとnonce検証

## ユーザーから必要な入力

### 必須
- `slug`（例: `sem32`）

### 任意
- 日時メタキー名（運用上固定があれば）
- デフォルトボタン文言
- UTM付与有無
- 新規タブ遷移有無

## 受け入れ条件
- `[tcj_webinar_cta slug="sem32"]`でCTAが表示される
- タイトル/URL/画像が対象ページと一致する
- 取得失敗時も記事表示が崩れない
- 設定変更が全記事へ反映される
