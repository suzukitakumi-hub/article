# プロフェッショナルAI記事執筆ワークフロー
# 心理分析 × 人間介入型AIプロセス

このワークフローは、**AIを「手足」として使いこなし、人間のインサイトとAIの処理能力を融合させて最高品質の記事を作成する**ためのシステムです。AIへの丸投げではなく、要所での人間介入（Human-in-the-loop）を前提とし、読者の深層心理に響く記事を構築します。

---

## 🔄 ワークフロー全体構造（全9ステップ）

```
【フェーズ1: 戦略・設計】
  【A】入力: ターゲットKW・裏テーマ・詳細指示
    ↓
  【B】調査: SERPs調査（現状把握）
  【C】分析: ユーザー心理予想（顕在・心理的負担・対策・潜在）
    ↓
  【D】構築: 記事骨子の組み立て・読者ゴールの設定

【フェーズ2: 構成・執筆】
  【E】構成: 見出し構成の作成（AI + 人間修正）
    ↓
  【F】設定: パーマリンク・メタディスクリプション作成
    ↓
  【G】執筆: 本文作成（見出しごとの生成・範囲指定生成）

【フェーズ3: 調整・完成】
  【H】介入: 人間による修正・調整（常時可能）
    ↓
  【I】完成: 文章調整・最終出力
```

---

## 📋 フェーズ1: 戦略・設計（ステップA-D）

### 【A】ターゲットKWの設定＋追加情報の入力

**重要**: ここはAIの関与がない「唯一の聖域」です。あなたの思い、戦略、裏テーマを自由に書き殴ってください。

**入力項目:**
1.  **ターゲットキーワード** (例: `クレジットカード おすすめ`)
2.  **記事の目的・裏テーマ**
    - 「読者の悩みに寄り添うフリをして、最終的に○○（商標）を成約させる」
    - 「競合他社を徹底的に比較し、自社の優位性を論理的に証明する」
    - 「読者の不安を煽り、これがないと危険だと思わせる（※倫理的配慮必須）」
3.  **商標・誘導先** (具体的な商品名、LPのURL)
4.  **雰囲気・トーン** (例: 「親身な先輩」「辛口な評論家」「論理的な専門家」)
5.  **参考情報** (社内資料、ターゲット読者のペルソナ詳細など)

---

### 【B】SERPs調査 & 【C】ユーザー心理予想（並列処理）

**実行内容:**
SERPs（検索結果）は「答え」の宝庫であり、読者の「SOS」の集積地です。

1.  **【B】SERPs調査**:
    - 実際にターゲットKWで検索し、上位記事の傾向を目視確認。
    - 「何が書かれているか」よりも「**なぜこの記事が上位なのか**」を分析。
    - 2025年以降の最新トレンドや、競合が見落としている穴を探す。

2.  **【C】検索ユーザーの心理予想**:
    - 検索行動の裏にある感情を読み解く。
    - 単なる「知りたい」だけでなく、「不安」「焦り」「怒り」「諦め」などの感情を特定。

---

### 【D】記事骨子の組み立て（最重要パート）

収集した【B】【C】の情報を統合し、記事の設計図を作成します。**検索意図の4層分析**を用いて、読者の心を鷲掴みにする構造を作ります。

#### 🧠 検索意図の4層分析フレームワーク

読者のニーズを以下の4層に分解・整理します。

1.  **顕在ニーズ** (Surface Needs)
    - 読者が明確に認識している問題や疑問。検索窓に入力した言葉そのもの。
    - 例: 「楽天カードの審査は厳しい？」

2.  **心理的負担** (Psychological Burden)
    - 検索行動の背景にある不安、ストレス、迷い、痛み。
    - 例: 「審査に落ちたら恥ずかしい」「信用情報に傷がつくのが怖い」「お金に困っていると思われたくない」

3.  **心理的負担を和らげる対策** (Relief & Solution)
    - 上記の負担を解消するための安心感を与える表現、提案、共感。
    - 例: 「実は主婦でも通りやすい」「審査落ちの履歴は6ヶ月で消えるから大丈夫」

4.  **潜在ニーズ** (Latent Needs)
    - 読者がまだ気づいていないが、解決した先にある真の願望や関連する課題。
    - 例: 「審査が緩いカードで実績を作って、将来はゴールドカードを持ちたい」「ポイントで生活費を浮かせて、たまには贅沢したい」

#### 記事の本軸と読者ゴール

- **記事の本軸**:
    - **具体的な解決手順**: トラブル解決のためのステップバイステップ。
    - **事実・真実**: この世の事象の原因や不変の事実。
    - （例外: 体験談、未来予測）
- **読者のゴール設定**:
    - **成功シナリオ**: 記事を読み、行動した読者が辿り着く理想の未来。
    - **失敗シナリオ**: 記事を素通りし、行動しなかった読者が陥る未来（損失回避の提示）。

---

## 📝 フェーズ2: 構成・執筆（ステップE-G）

### 【E】見出し構成の作成

**実行内容:**
【D】で構築した骨子を元に、H2・H3の見出し構成を作成します。

- **AIの活用**: 構造化はAIが得意とする分野。指示通りの論理構成を一瞬で出力させます。
- **人間介入ポイント**:
    - AI特有の不自然な言い回し（「○○への最短ステップ！」「究極のガイド」等）を修正。
    - 文脈の流れ（ストーリーライン）が自然か確認。

### 【F】パーマリンク・メタディスクリプション作成

- **実行内容**: 記事の内容に基づき、SEOに最適化されたメタディスクリプションと、英単語ベースのパーマリンクを作成する。
- **注意点**: 既存記事とのカニバリゼーション（重複）防止のため、パーマリンクのユニーク性を意識する。

---

### 【G】記事本文の作成（人間介入型生成）

**重要**: AIに「全部書いて」と丸投げすることは避け、**分割生成**でクオリティを担保します。

**推奨される生成手法（3択）:**

1.  **見出しごとの生成**:
    - H2単位、あるいはH3単位で細かく生成指示を出す。
    - 直前の文脈を人為的に調整しながら進められるため、最も高品質。

2.  **範囲指定生成**:
    - 「導入文から最初のH2まで」「H2-3からまとめまで」のように範囲を指定。
    - 流れを重視したい箇所に有効。

3.  **一括生成（修正前提）**:
    - 全体を一気に生成させる。
    - スピードは早いが、後半につれて論理が破綻したり、指示忘れが発生しやすい。
    - **API利用の注意**: コンテキスト（文脈）を維持するために過去の生成文を再読み込みさせると、トークン消費量が激増するため注意が必要。

---

## 🔧 フェーズ3: 調整・完成（ステップH-I）

### 【H】人間による修正・調整（常時可能）

**このワークフローの核心**です。記事作成完了まで、**どこでも・いつでも人間が介入できる状態**を保ちます。

- **介入のアクション例**:
    - AIが書いた文章のニュアンス修正
    - 体験談や独自エピソードの加筆（AIには書けない「生」の情報）
    - 不要なリストや過剰な装飾の削除
    - 接続詞や語尾の調整（AI臭の排除）

**「AIに任せる」のではなく、「AIと一緒に書く」。主導権は常に人間が持ちます。**

### 【I】文章のみの記事完成

- 装飾や画像はこの段階では必須ではありません。まずは「読ませる文章」として完成させます。
- 最終的な出力形式（HTML、Markdown等）に合わせて整えます。

---

## ⚠️ 執筆時の品質基準（ライティングルール）

AI生成テキストには特有の「癖」があります。以下のルールに基づき、必ず修正を行ってください。

### 1. 禁止キーワードの排除
以下の単語は**使用禁止**です。文章の意味を損なわない範囲で言い換えてください。

| 禁止KW | 言い換え例 |
| :--- | :--- |
| **ニーズ** | 求めていること、要望 |
| **セクション** | 項目、章 |
| **示します** | 説明します、紹介します |
| **提供** | 届ける、用意する |
| **考慮** | 検討する、踏まえる |
| **活用** | 使う、役立てる |
| **存在** | いる、ある |
| **特定** | 具体的な、決まった |
| **向上** | 高まる、伸びる |
| **アプローチ** | 方法、取り組み |
| **スムーズ** | 円滑に、滞りなく |

### 2. AI臭い表現の排除
- **煽り・誇張**: 「圧倒的No.1」「明日から使える！」「キレイごとは抜きです」は削除。
- **記号の乱用**: 「——」（ダッシュ）の多用は禁止（1記事2回まで）。
- **不自然な接続詞**: 「しかしながら」「また、」「さらに、」の連続使用を避ける。

### 3. 人間味のある文章へ（8つの技法）
1.  **読者の心理を言語化する**: 「〜とお悩みではありませんか？」と先回りして共感する。
2.  **対話を演出する**: 問いかけや、筆者の主観（「個人的には〜」）を適度に混ぜる。
3.  **動きのある動詞を使う**: 「採用する」→「迎え入れる」、「改善する」→「浮き彫りにする」。
4.  **生活シーンへの翻訳**: 専門用語やスペックを、日常の具体的なシーンに例える。
5.  **日常的な比喩**: 誰もが知っているモノやコトで例える。
6.  **メリット・デメリットの公平性**: デメリットも正直に伝え、信頼を獲得する。
7.  **五感に訴える描写**: 質感、空気感、安心感などを感覚的な言葉で表現する。
8.  **印象的な締めくくり**: セクションの最後に、本質を突く一言や次の行動への示唆を置く。

## 📢 自動実行時の注意

このワークフローをAIエージェントで自動実行する場合、以下の点に留意してください。

1.  **「人間の代わり」になろうとしない**: 
    - ユーザーが入力した【A】の指示（特に裏テーマや思い）を最優先する。
    - 独自の判断で勝手に方向性を変えない。
2.  **検索意図の4層分析を徹底する**:
    - 顕在ニーズだけでなく、必ず「心理的負担」「潜在ニーズ」まで深掘りして構成案を提示する。
3.  **ステップごとに確認を求める**:
    - 一気に最後まで生成せず、構成案（【E】）の段階で一度ユーザーの承認を得ることを推奨する。
