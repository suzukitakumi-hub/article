# Phase5：検証・最終出力

## このスキルを使うとき
- seo-articleワークフローのPhase5実行時
- 記事の品質チェック・検証を依頼されたとき

## このスキルを使わないとき
- Phase4が未完了のとき

## セッション開始前チェック（必須・スキップ禁止）
1. `.agent/lessons.md` を読み、Phase5または検証に関連する教訓を確認する
2. `data/phase_outputs/phase4_output.json` の存在を確認する（なければPhase4のゲートJSON出力からやり直す）
```bash
python .agent/scripts/gate_check.py --phase 4 --file data/phase_outputs/phase4_output.json
```
→ EXIT 1 の場合はPhase5を開始しない。

## 手順

### Step1：機械バリデーション【最優先・省略禁止】

Phase4の出力（HTMLファイル）に対して、バリデーションスクリプトを実行する。

**⚠️ 絶対ルール（違反禁止）：**
1. **スクリプトの内容を変更してはならない。** 引数形式、チェックロジック、出力形式を一切改変しないこと。
2. **引数形式は必ず以下の通りにすること。** 省略・変形禁止。
3. **スクリプトの出力する「本文文字数」がプレーンテキストの実文字数である。** HTMLタグ込みの文字数をユーザーに報告してはならない。

```bash
# 実行コマンド（この形式を厳守）
python3 .agent/skills/seo-phase5-validation/scripts/validate_article.py \
  article.html \
  --title "実際のタイトル文字列" \
  --target-chars Phase3で計画した文字数
```

スクリプトがチェックする項目：
- 禁止ワード13語（「特定技能」等の固有名詞は自動除外）
- 禁止比喩（羅針盤、DNA等）
- 安全クッション語（一般的に、多くの場合等）
- 締め定型句（いかがでしたか等）
- メタ表現（この記事では、本稿では、本記事では等）
- 語尾3連続（です。です。です。等）
- 感嘆符（！）の上限（2回まで）
- コロン＋半角スペース（「： 」）
- タイトル文字数（28〜36文字）
- 年号の現在年チェック（タイトル・本文の「20XX年最新」「20XX年版」が現在年か）
- タイトルと本文の年号整合性
- FAQ数（最低5問）
- 本文文字数（プレーンテキスト、空白除く）のPhase3目標との±20%チェック

**スクリプトが全項目PASSするまで、Step2以降に進めない。**
違反があればPhase4に戻って修正→再実行を繰り返す。

### Step1.5：デザインテンプレ準拠チェック【必須】

Step1のPASS後、以下を実行してデザインテンプレ準拠を検証する。

```bash
python3 .agent/skills/seo-phase5-validation/scripts/validate_design_template.py article.html
```

チェック内容：
- `references/html-template.html` のWRAPPER基準（フォント、行間、最大幅）
- テーマ依存クラスの混入禁止（`p-column-detail` 等）
- 見出し（H2/H3/H4）のインラインスタイル必須
- 内部リンクカードのDOM構造一致（`references/internal-link-design.html`）
- `tcj-blogcard__*` 派生クラスの禁止
- 内部リンクカード画像のプレースホルダー禁止（`placehold.jp` / `placeholder`）

**このチェックがPASSするまでStep2以降に進めない。**

### Step1.6：文体（ですます調）チェック【必須】

Step1.5のPASS後、以下を実行してですます調を検証する。

```bash
python3 .agent/skills/seo-phase5-validation/scripts/validate_tone.py article.html
```

チェック内容：
- `だ` で終わる文（⇒ です）
- `である` で終わる文（⇒ です）
- `なのだ` / `だった` / `であった` で終わる文
- `ない` で終わる文（⇒ ません/ありません）
- `いる` で終わる文（⇒ います）
- `いた` で終わる文（⇒ いました）
- `した`（ただし `ました` / `でした` は除外）で終わる文（⇒ しました）

**⚠️ 語尾3連続対策との両立ルール：**
- `ない` → `ありません` / `ません`
- `いる` → `います`
- `した` → `しました`
- 上記でもstreakになる場合は **体言止め** または `〜といえます` `〜が重要です` `〜がポイントです` 等のですます語尾バリエーションで回避する。
- **だ・である調に逃げることは禁止。**

**このチェックがPASSするまでStep2以降に進めない。**

### Step2：文字数の正確な報告

Step1のスクリプト出力に含まれる「本文文字数（プレーンテキスト、空白除く）」を確認する。
ユーザーへの報告時は、**必ずこの数字を使うこと。**
HTMLソースコードの文字数を報告してはならない。

### Step3：LLMO対策チェック（AI判断）
- [ ] 各H2/H3の直下1〜2文で結論が述べられているか
- [ ] すべての統計データに出典名と年が明記されているか
- [ ] Q&A形式の見出しが含まれているか
- [ ] 比較・手順・リストが箇条書きか表で構造化されているか
- [ ] 記事冒頭に定義文（「〇〇とは、〜」）があるか
- [ ] FAQセクションに5問以上のFAQがあるか

### Step4：E-E-A-Tスコアカード評価（AI判断）
記事全体を5段階評価する。

Experience（経験）：
- 5点：複数の実体験・導入事例が具体的に記載
- 3点：事例1つのみ
- 1点：実体験・事例が全くない

Expertise（専門性）：
- 5点：専門家の独自見解・メソッドが複数含まれている
- 3点：専門用語は正確だが一般的な解説レベル
- 1点：一般論のみ

Authoritativeness（権威性）：
- 5点：公的データ＋自社実績数値＋第三者評価が全て揃っている
- 3点：公的データのみ
- 1点：客観的なデータが全くない

Trustworthiness（信頼性）：
- 5点：全データに出典明記＋事実確認済み＋誇大表現なし
- 3点：出典はあるが一部不明確
- 1点：出典なし・誇大表現あり

合計15点以上 → 合格。Step5に進む。
合計10〜14点 → 3点以下の要素を重点強化してからStep5に進む。
合計9点以下 → Phase4に戻り、1次情報の追加・USPの強化を行う。

### Step5：コンテンツ品質チェック（AI判断）
- [ ] 網羅性：競合の共通トピックがすべて含まれているか
- [ ] 深度：競合よりも深い情報、専門的な解説になっているか
- [ ] 独自性：自社にしか語れない事例やUSPが含まれているか
- [ ] 最新性：統計データや事例は最新のものか
- [ ] ペルソナ適合：想定読者の悩みに十分に答える内容か
- [ ] 文字数：Step1スクリプトの「本文文字数」がPhase3計画の±20%以内か
- [ ] 1次情報比率：記事全体の30%以上が1次情報で構成されているか
- [ ] BtoB最適化：決裁者が納得できる数字・論拠が含まれているか
- [ ] 内部リンク妥当性：内部リンクカードが最大3件で、`references/internal-link-list.md` に存在するURLのみを使用しているか
- [ ] クラスター整合：`references/topic-cluster-map.md` と `references/internal-link-selection-rules.md` に沿った選定になっているか
- [ ] 空虚長文排除：抽象語や同義語の反復で文章を水増ししていないか（具体策・根拠が伴っているか）
- [ ] 根拠トレーサビリティ：主要主張5件以上が出典（機関名・年）と一致しているか

### Step6：公開後改善タスクの作成
最終出力に、公開後の改善ループを必ず含める。

- 14日後チェック：Impressions上位クエリのCTR改善余地（低CTR）を抽出
- 30日後チェック：平均掲載順位11〜20位クエリのセクション追記候補を抽出
- 各チェックで「見る指標」「判定基準」「実施アクション（見出し修正/FAQ追加/タイトル調整）」を1行ずつ記載

### Step7：最終出力
すべてのチェックに合格したら以下を出力する。
- 完成版HTML（WordPressのカスタムHTMLブロックに貼り付け可能）
- タイトルとメタディスクリプション（プレーンテキスト）
- 画像プレースホルダー一覧（箇所と内容説明）
- **本文文字数（Step1スクリプトの出力値をそのまま記載）**
- 公開後改善タスク（14日後/30日後）

出力後、メタコメント（「以上です」「修正があれば」等）は一切付けない。
