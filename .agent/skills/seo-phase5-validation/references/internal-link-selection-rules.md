# Internal Link Selection Rules

このルールは、記事執筆時に内部リンクを「乱発せず」「クラスタに沿って」配置するための実装基準。

## 基本ルール（デフォルト）
- 内部リンクカードは1記事あたり最大3件。
- 3件のうち、同一クラスターから2件以上を選ぶ。
- クラスター外リンクは原則禁止。
- URLは `internal-link-list.md` に存在するもののみ使用可。
- 出力形式は `internal-link-design.html` のHTMLカードのみ。
- Markdownリンク（`[text](url)`）は本文に出力しない。

## 例外ルール
- 同一クラスターで候補が2件未満の場合のみ、隣接クラスターから最大1件追加可。
- 例外を使う場合は、採用理由を1行で明記する。
- 隣接判定は `topic-cluster-map.md` のみを正とする。

## 配置ルール
- セクション内容に直接関連する箇所に配置する。
- 同じH2直下に複数カードを連続配置しない。
- FAQ内には原則配置しない（可読性維持のため）。

## 品質ルール
- 誘導文は短く、本文の流れを壊さない。
- アンカーテキストは記事タイトルをそのまま使う。
- 同一URLの重複挿入は禁止。

## 実務チェック（Phase4完了前）
- 件数が3件以内か
- 2件以上が同一クラスターか
- 全URLが許可リスト内か
- すべてHTMLカード形式か
