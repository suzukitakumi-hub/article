# Phase2：競合調査＋ギャップ分析

## このスキルを使うとき
- seo-articleワークフローのPhase2実行時
- 競合分析やギャップ分析を依頼されたとき

## このスキルを使わないとき
- Phase1が未完了のとき
- Phase3以陆の作業時

## セッション開始前チェック（必須・スキップ禁止）
1. `.agent/lessons.md` を読み、Phase2または競合分析に関連する教訓を確認する
2. `data/phase_outputs/phase1_output.json` が存在するかを確認する（なければPhase1からやり直す）
3. `data/phase_outputs/phase2_output.json` が存在する場合は削除してから開始する

## 手順

### Step1：PAA＋関連検索の収集
{target_keyword}で検索し、以下を収集する。

PAA質問を4分類で整理：
- What系：定義・概要を知りたい
- How系：方法・手順を知りたい
- Why系：理由・背景を知りたい
- Which系：選択肢を知りたい

関連検索キーワードを優先順位で整理：
- 高優先度：記事内で必ず触れるべきトピック
- 中優先度：別記事として独立させるべきトピック
- 低優先度：今回は触れない

### Step1.5：SERanking 競合KW補強（MCPが使える場合は必須）

`get_competitor_keywords` を呼び出す:
- `days`: 30
- `limit`: 50

取得データから `{target_keyword}` に関連するKWを抽出し、以下の視点でStep1の関連検索リストを補強する:

- **競合が持っていてTCJにないKW**: 記事で追加すべきトピック候補
- **ボリューム上位の共通KW**: 競合全体が攻めている角度 → 必ず記事でカバー
- **suggested_bid が高くTCJが圏外のKW**: 商業価値の高い差別化ポイント

補強後、Step1の「関連検索キーワードの優先順位」にこのデータを統合して出力する。

SERanking MCPが利用不可の場合は「MCP競合補強なし」と1行記載してStep2に進む。

### Step2：競合上位5サイトのループ分析【最重要・省略禁止】

**絶対ルール：1サイトの分析が完了してから次のサイトに進む。まとめて処理しない。**

{target_keyword}の検索結果上位5サイトを、1サイトずつ順番に分析する。
各サイトについて実際にURLを訪問し、以下を記録する。

1サイトごとの記録項目：
- 順位とURL
- タイトル（文字数を含む）
- 総文字数（概算）
- H2見出し一覧（すべて列挙）
- H3見出し一覧（各H2配下のH3をすべて列挙）
- 図表の数（表、リスト、画像の概数）
- 引用データと出典（どの省庁・機関のデータを使っているか）
- 独自コンテンツ（そのサイトにしかない情報）
- CVポイント（CTAの位置と内容）
- BtoB向きかBtoC向きか

処理手順（厳守）：
1. サイト#1をブラウジング → 記録を出力
2. サイト#2をブラウジング → 記録を出力
3. サイト#3をブラウジング → 記録を出力
4. サイト#4をブラウジング → 記録を出力
5. サイト#5をブラウジング → 記録を出力

アクセスできないサイトはスキップし、スキップした旨を記録して次に進む。

### Step3：検索意図充足度スコアリング
各競合サイトがPhase1の4要素をどこまでカバーしているかをスコアリングする。

スコアリング基準：
- ○（1点）：十分に答えている
- △（0.5点）：部分的に答えている
- ×（0点）：答えていない

各サイトの4要素スコア（合計4点満点）を記録する。

### Step4：統合レポート＋ギャップ分析
5サイトの分析結果を統合し、以下を出力する。

- 共通トピック一覧：上位5サイト中、4サイト以上が扱っているトピック → 記事に必須
- 差別化トピック一覧：1〜2サイトのみが扱っている独自トピック → 取り入れを検討
- 自社が勝てるポイント：競合が弱い部分で、自社の強みが活きる部分（references/tcj-company-profile.mdを参照）
- 4要素ギャップ分析：競合全体で弱い要素はどれか。そこを重点的に攻める方針を立てる
- 差別化の軸：「この記事でしか得られない情報」を1行で言語化する

## ゲート条件（すべて満たすまで次のPhaseに進めない）

**【機械ゲート】Phase3を開始する前に必ず実行すること：**
```bash
python .agent/scripts/gate_check.py --phase 2 --file data/phase_outputs/phase2_output.json
```
→ EXIT 0 になるまでPhase3を開始しない。

**Phase4のStep4実行後、以下形式でJSONを出力すること（必須）：**
`data/phase_outputs/phase2_output.json` に実際の分析結果を埋める。
値は空配列・空文字禁止。

- [ ] PAA質問の分類結果を出力済み
- [ ] 関連検索キーワードの優先順位を出力済み
- [ ] 上位5サイトの個別分析を完了（5サイト分 or スキップ理由を明記）
- [ ] 検索意図充足度スコアリングを出力済み
- [ ] 共通トピック一覧を出力済み
- [ ] 差別化トピック一覧を出力済み
- [ ] ギャップ分析を出力済み
- [ ] 差別化の軸（1行）を出力済み
- [ ] `data/phase_outputs/phase2_output.json` を出力し、機械ゲートがEXIT 0になった
