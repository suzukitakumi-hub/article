# HTMLテンプレート パーツ使い分けガイド

## デザイン仕様
- ブランドカラー: #102891（濃紺）
- テキストカラー: #424242
- 背景: #fff
- フォント: 'acumin-pro', 'Noto Sans JP', sans-serif
- 行間: 1.8
- 最大幅: 900px
- テーブルヘッダー背景: #f0f4f8
- ボーダー: #e1e1e1（テーブル）, #102891（ボックス・見出し）

## パーツ一覧と使い方
- パーツ1（リード文）：記事冒頭に1回のみ
- パーツ2（H2見出し）：大セクションの区切り。5〜8個が目安
- パーツ3（H3見出し）：中セクション。各H2配下に2〜5個が目安
- パーツ4（H4見出し）：小セクション。必要な場合のみ
- パーツ5（本文段落）：通常のテキスト
- パーツ6（強調段落）：1セクション内で1〜2箇所が上限
- パーツ7（ボックスリスト）：ポイント列挙、要件リスト、メリット・デメリット
- パーツ8（シンプルリスト）：ボックス内のサブリスト、補足的な列挙
- パーツ9（比較表）：在留資格比較、料金比較、サポート一覧など
- パーツ10（CSSバーチャート）：数値データの視覚化。1記事内に1〜2個
- パーツ11（事例ボックス）：失敗パターン、成功事例、ケーススタディ
- パーツ12（FAQ）：記事末尾に5問以上
- パーツ13（企業紹介カード）：おすすめ企業の紹介。自社は詳細に、他社は簡潔に
- パーツ14（CTA）：記事末尾のコンバージョンエリア。記事中盤にも配置可
- パーツ15（出典付き画像）：公的データの図表埋め込み

## CTA配置ルール
- 記事中盤（全体の50〜60%の位置）にパーツ13またはパーツ14で1つ
- 記事末尾にパーツ14で1つ
- CTAのリンク先：tcj-company-profile.md内のURLを使用
- 「資料請求する（無料）→」のようなボタンテキスト

## 画像の扱い
- 引用可能な既存画像（公的機関のグラフ等）：パーツ15で埋め込む。出典URLを明記
- ユーザーが後で用意する画像： <!-- 画像挿入箇所：{{画像の内容説明}} --> のプレースホルダー
- 図解の新規作成は行わない
- すべての画像にalt属性を設定する

## 最終出力形式
- WRAPPERの開始タグから閉じタグまでの1つのHTMLブロック
- DOCTYPE宣言やhead要素は含めない（WordPressのカスタムHTMLブロックに貼り付ける前提）
