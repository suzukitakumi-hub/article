# LLMO対策ルール（AI検索最適化）

## 構造ルール
- 結論ファースト：各H2/H3の直下1〜2文で、そのセクションの結論を端的に述べる
- 定義文：記事の冒頭（リード文の直後、または最初のH2の直後）で「〇〇とは、〜である」と1文で定義する
- 箇条書き・表の構造化：比較、手順、リストは必ず箇条書きか表で構造化する
- 統計データ＋出典＋年：すべてのデータに出典名と年を明記する
- Q&A形式の見出し：記事内に「〜とは？」「〜のメリットは？」形式の見出しを含める
- FAQセクション：記事末尾に5問以上のFAQを設置する

## 注意事項
- 過度な最適化は避ける。ユーザー体験を損なうほどAIに最適化しない
- 「結論：」「ポイント：」のようなラベル装飾は不要。自然な文章で結論から書く
- 構造化データ（JSON-LD）は記事HTML内には含めない
